# Mirrored tool archives

Copies of third-party release archives that the zetaphy audit pipeline (`audit/tools/install.sh`) pins by
SHA-256 and that are no longer downloadable upstream. The installer checks the same SHA-256 as for the
upstream file, so a mirror cannot change what runs.
